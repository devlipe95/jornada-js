Diário de um webmaster

Hoje eu estava mexendo nos meus arquivos antigos e acabei encontrando uma coisinha que achei que seria legal mostrar aqui no blog. É um pequeno arquivo de estudos que estava guardado por aqui há algum tempo.

While

Use While para:

  • A - Contar de 1 a 10
  • B - Somar de 1 a 10
  • C - Contagem regressiva de 10 a 1
Confira essa página com f12(inspecionar) na aba console do DevTools para ver as respostas!

Mas afinal, o que é While?

Ótima pergunta pequeno gafanhoto! e a resposta é simples... é a mesma coisa que o loop, porém se usa de um jeito diferente.

Exemplo: no loop tradicional, para você fazer uma contagem de 1 a 10 precisa escrever: 

  
    for (let x = 1; x <= 10; x=x+1) {
      console.log("Número: " + x);
    }

Com While você escreve: 

      const limite = 10;
      let X = 1;

      while (X <= limite) {
        console.log(X);
        X++;
      }

E o que isso quer dizer?

Vamos por partes

  • const significa constante, um valor imutável
  • let significa um valor que muda
  • While significa Enquanto
  • X++ significa X + X = X

Em outras palavras, o código pode ser lido como:

O limite é 10, X começa valendo 1, e Enquanto X não for maior que 10, fique contando X + X = X

Ou seja:

    O programa vai fazer 1 + X = 1 (agora ele sabe que X vale 1)
    Depois vai fazer 1 + 1 = 2 (agora ele sabe que X vale 2)
    Depois vai fazer 1 + 2 = 3 (agora ele sabe que X vale 3)
    E enquanto X não tiver valendo 10 ele vai continuar nisso

E porque existe duas formas de fazer exatamente a mesma coisa?
