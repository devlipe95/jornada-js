Crie uma pagina com:

  • A - Um título principal na página com id="titulo"
  • B - Um botão para mudar a cor do título para azul
  • C - Um botão para mudar o texto do título
  • D - Um botão para esconder o título (usando style.display = "none")
  • E - Um botão para mostrar o título de volta (usando style.display = "block")

Explicação do JS

Código utilizado:

const titulo = document.getElementById('titulo');
            const btnCor = document.getElementById('btnCor');
            const btnTexto = document.getElementById('btnTexto');
            const btnEsconder = document.getElementById('btnEsconder');
            const btnMostrar = document.getElementById('btnMostrar');
            
            btnCor.addEventListener('click', function() {
                titulo.style.color = 'blue';
            });
            
            btnTexto.addEventListener('click', function() {
                titulo.textContent = 'Texto Alterado com Sucesso! 🚀';
            });
            
            btnEsconder.addEventListener('click', function() {
                titulo.style.display = 'none';
            });
            
            btnMostrar.addEventListener('click', function() {
                titulo.style.display = 'block';
            });

Traduzindo o script para português:

O bloco inicial começa declarando os slots const titulo e os quatro botões usando document.getElementById(...). Sabendo que const cria um slot com valor imutável e getElementById busca os elementos pelo seu identificador único na página.
Traduzindo as 5 primeiras linhas: "No HTML, procure pelo título e pelos quatro botões através de seus IDs, e guarde cada um em seu respectivo slot."

Na instrução btnCor.addEventListener('click', function() { ... }); temos o ouvinte de cliques atrelado ao primeiro botão.
Dentro desse bloco, a linha titulo.style.color = 'blue'; usa a propriedade style.color (que acessa a cor do texto no estilo CSS) e atribui a cor azul.
Traduzindo o primeiro botão: "Avisamos ao 'btnCor' para escutar o clique. Quando for clicado, mude a propriedade de cor do texto do título para azul."

No segundo botão temos btnTexto.addEventListener('click', function() { ... });.
A linha interna titulo.textContent = 'Texto Alterado com Sucesso! 🚀'; utiliza a propriedade textContent para reescrever o que está escrito no título.
Traduzindo o segundo botão: "Avisamos ao 'btnTexto' para escutar o clique. Quando for clicado, altere o conteúdo escrito do título para 'Texto Alterado com Sucesso! 🚀'."

No terceiro botão temos btnEsconder.addEventListener('click', function() { ... });.
A linha interna titulo.style.display = 'none'; acessa o estilo de exibição da tag no CSS e define o valor como none (que significa oculto/invisível).
Traduzindo o terceiro botão: "Avisamos ao 'btnEsconder' para escutar o clique. Quando for clicado, mude a exibição (display) do título para 'none', fazendo ele desaparecer da tela."

No quarto botão temos btnMostrar.addEventListener('click', function() { ... });.
A linha interna titulo.style.display = 'block'; define a exibição da tag de volta para o padrão de elementos em bloco, tornando-a visível novamente.
Traduzindo o quarto botão: "Avisamos ao 'btnMostrar' para escutar o clique. Quando for clicado, restaure a exibição (display) do título para 'block', fazendo ele reaparecer na tela."

Resumo final:

Juntando todas essas traduções, o código está dizendo: "Guarde o título e os quatro botões em slots. Fique escutando os cliques: se clicar no primeiro botão, mude a cor do título para azul; se clicar no segundo, altere o texto escrito; se clicar no terceiro, defina a exibição como 'none' para escondê-lo; e se clicar no quarto, defina a exibição como 'block' para trazê-lo de volta."
