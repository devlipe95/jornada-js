Código do Script

let numeros = [10, 20, 30, 40, 50];
              
              // a- Use for para mostrar cada número com a posição
              console.log("--- Posições e Números ---");
              for (let i = 0; i < numeros.length; i++) {
                console.log(`Posição ${i}: ${numeros[i]}`);
              }
              
              // b- Use forEach para mostrar o dobro de cada número
              console.log("--- Dobro de cada Número ---");
              numeros.forEach((numero) => {
                console.log(`O dobro de ${numero} é ${numero * 2}`);
              });

Dissecando o Script: Estruturas de Repetição em Arrays

Neste exercício, exploramos duas maneiras clássicas de percorrer (iterar sobre) uma lista no JavaScript: o loop tradicional for e o método moderno forEach.

1. Loop Tradicional for

  • let i = 0: Inicializa a variável contador i apontando para o primeiro índice do array (posição 0).
  • i < numeros.length: Condição de parada. O loop continua rodando enquanto i for menor que a quantidade total de elementos (5).
  • i++: Incrementa o valor de i em +1 a cada volta.
  • numeros[i]: Acessa o valor do elemento no índice atual da repetição.

2. Método forEach

  • numeros.forEach(...): Método nativo de arrays que executa uma função para cada item da lista automaticamente, sem precisar controlar o contador manualmente.
  • (numero) => { ... }: Parâmetro da função que recebe o valor do elemento atual a cada volta.
  • numero * 2: Multiplica o valor atual por 2 para calcular e exibir o seu dobro no console.
