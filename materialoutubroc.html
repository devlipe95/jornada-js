O que é uma Landing Page?

Uma Landing Page (ou "página de destino") é uma página web criada especificamente para focar a atenção do visitante em um único objetivo ou ação principal (como clicar em um botão de cadastro, comprar um produto ou conhecer um recurso), com título impactante e poucos elementos de distração.

Como o título foi centralizado e destacado?

Utilizamos as classes utilitárias do Bootstrap text-center para centralizar o texto horizontalmente e mb-3 para criar uma margem inferior. No CSS, definimos o tamanho da fonte com font-size: 2.5rem para deixá-lo bem visível.

Como funciona a animação pulsante no botão principal?

Criamos uma regra de animação com @keyframes pulsoInfinito. Ela faz o botão aumentar suavemente de tamanho (até 108% do tamanho original) enquanto expande um anel transparente azul ao seu redor (simulado pela propriedade box-shadow), gerando um efeito contínuo de atenção.

Como funcionam os efeitos hover nos botões e no card?

Utilizamos o seletor :hover no CSS junto com a propriedade transform: translateY(). Quando o leitor passa o ponteiro do mouse sobre o botão ou card, ele se desloca alguns pixels para cima e a sua sombra se projeta para baixo, simulando um efeito tátil de elevação.

O que é o componente Card do Bootstrap?

O card é uma caixa flexível do Bootstrap usada para organizar informações relacionadas em um único bloco. Ele permite agrupar ícones/imagens, títulos e textos de forma limpa e elegante.
