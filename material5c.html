ATIVIDADE — Primeira Função

  • Crie duas vezes função que:
  • 1- Recebe um nome
  • 2- Mostra "Olá, [nome]!"
*Confira essa página com f12(inspecionar) na aba console do DevTools para ver as respostas!
Clique aqui para ver a resolução e explicação do Desafio: Primeira Função

Código do Desafio

// 1. Forma tradicional (Sintaxe Standard)
              function saudarTradicional(nome) {
                console.log(`Olá, ${nome}!`);
              }
              
              // 2. Forma moderna (Arrow Function)
              const saudarArrow = (nome) => {
                console.log(`Olá, ${nome}!`);
              };
              
              // Executando as duas funções para testar
              saudarTradicional("Feliphe");
              saudarArrow("Maria");

Dissecando o Script: Entendendo as Duas Formas

Para cumprir o desafio de criar a mesma função de duas formas diferentes no JavaScript, utilizamos os dois estilos mais comuns: a Declaração Tradicional e a Arrow Function.

1. Forma Tradicional (saudarTradicional)

  • function saudarTradicional(nome): Declara uma função nomeada que recebe o parâmetro nome.
  • console.log(`Olá, ${nome}!`);: Usa Template Literals para interpolar a variável nome dentro da mensagem de saudação.

2. Forma Moderna / Arrow Function (saudarArrow)

  • const saudarArrow = ...: Declara uma constante que armazenará a função.
  • (nome) => { ... }: Sintaxe de Arrow Function (sinal de igual seguido de maior que =>). É uma forma mais curta e moderna de escrever funções no JavaScript.

3. Execução das Funções

  • saudarTradicional("Feliphe");: Chama a primeira função passando o texto "Feliphe" como argumento, exibindo Olá, Feliphe! no console.
  • saudarArrow("Maria");: Chama a segunda função passando "Maria", exibindo Olá, Maria! no console.
