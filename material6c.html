Código do Script

let numeros = [10, 20, 30];
              console.log("Inicio:", numeros); // [10, 20, 30]
              
              // a- Adiciona 40 no final
              numeros.push(40);
              console.log("Após push(40):", numeros); // [10, 20, 30, 40]
              
              // b- Adiciona 5 no início
              numeros.unshift(5);
              console.log("Após unshift(5):", numeros); // [5, 10, 20, 30, 40]
              
              // c- Remova o último
              numeros.pop();
              console.log("Após pop():", numeros); // [5, 10, 20, 30]
              
              // d- Remova o primeiro
              numeros.shift();
              console.log("Após shift():", numeros); // [10, 20, 30]

Dissecando o Script: Métodos Principais de Arrays

Neste exercício, exploramos os quatro métodos fundamentais do JavaScript para adicionar e remover elementos nas extremidades de um Array.

1. Adicionando Elementos

  • .push(valor): Adiciona um elemento ao final do array. No exemplo, o número 40 foi inserido após o 30.
  • .unshift(valor): Adiciona um elemento no início do array (índice 0) e desloca todos os outros itens para a direita. O número 5 passou a ser o primeiro elemento.

2. Removendo Elementos

  • .pop(): Elimina o último elemento do array. Como o último item era 40, ele foi removido.
  • .shift(): Elimina o primeiro elemento do array e ajusta os índices dos demais itens para a esquerda. O número 5 foi removido, fazendo o array retornar ao seu estado inicial.

3. Dica para Guardar Fácil

  • Início do Array: unshift (adiciona) / shift (remove)
  • Final do Array: push (adiciona) / pop (remove)
