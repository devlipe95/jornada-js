Diário de um webmaster

Hoje eu estava mexendo nos meus arquivos antigos e acabei encontrando uma coisinha que achei que seria legal mostrar aqui no blog. É um pequeno arquivo de estudos que estava guardado por aqui há algum tempo.

Crie funções para:

  1. 1- somar(a, b)
  2. 2- subtrair(a, b)
  3. 3- multiplicar(a, b)
  4. 4- dividir(a, b)
*Confira essa página com f12(inspecionar) na aba console do DevTools para ver as respostas! Meu A vale 10 e o B vale 5!
Clique aqui para ver a resolução e explicação do Exercício: Quatro Operações Matemáticas

Código do Script

// 1. Função para Somar
  function somar(a, b) {
    return a + b;
  }
  
  // 2. Função para Subtrair
  function subtrair(a, b) {
    return a - b;
  }
  
  // 3. Função para Multiplicar
  function multiplicar(a, b) {
    return a * b;
  }
  
  // 4. Função para Dividir
  function dividir(a, b) {
    if (b === 0) {
      return "Erro: Divisão por zero!";
    }
    return a / b;
  }
  
  // Testando as funções
  console.log(somar(10, 5));        // 15
  console.log(subtrair(10, 5));     // 5
  console.log(multiplicar(10, 5));  // 50
  console.log(dividir(10, 5));      // 2
  console.log(dividir(10, 0));      // Erro: Divisão por zero!

Dissecando o Script: Entendendo as Operações Básicas

Neste exercício, criamos quatro funções separadas para realizar cada uma das operações fundamentais da matemática em JavaScript.

1. As Quatro Funções Principais

  • somar(a, b): Utiliza o operador aritmético + para somar os valores de a e b.
  • subtrair(a, b): Utiliza o operador - para calcular a diferença entre a e b.
  • multiplicar(a, b): Utiliza o operador * para multiplicar a por b.
  • dividir(a, b): Utiliza o operador / para dividir a por b.

2. Uso do Comandos return e Validação

  • return: Instrução que faz a função devolver o resultado do cálculo para onde ela foi chamada.
  • Validação de segurança (if (b === 0)): Na função de divisão, verificamos se o divisor b é igual a zero, evitando um resultado matematicamente inválido (Infinity) e retornando uma mensagem amigável.

3. Execução e Teste

  • Ao passar os números como argumentos entre parênteses (ex: somar(10, 5)), cada função executa sua respectiva conta e devolve o valor para ser exibido pelo console.log().
