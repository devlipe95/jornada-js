Diário de um webmaster

Hoje eu estava mexendo nos meus arquivos antigos e acabei encontrando uma coisinha que achei que seria legal mostrar aqui no blog. É um pequeno arquivo de estudos que estava guardado por aqui há algum tempo.

Ei você, sim você mesmo, você sabe o que é um arrays?

Vou fingir que você disse "não" e vou te explicar! O Arrays surge de uma mina chamada Rayssa, mas que todos chamavam de Ray, e ela tinha um infeliz problema de asma, como era de costume ela usava varias const de forma isolada pra respirar, desse jeito:

  • const respiração1 = "Ar";
  • const respiração2 = "Ar"
  • ;const respiração3 = "Ar";

Mas então ela inovou, e pensou numa nova forma revolucionaria de respirar, e ficou assim:

    const respiração = ["Ar", "Ar", "Ar"];

e todo mundo começou a usa a ideia dela, e dai sempre falavam "uau que ideia fantástica! quem fez?" e respondiam "A ray" e com o tempo, o apelido ficou "arrays"!

Ok, agora a explicação cientifica e simples, isso serve pra colocar varias variáveis com apenas um comando

Crie 3 arrays:

  • a- Nomes de 3 frutas
  • b- 5 números
  • c- Cores favoritas (4 cores)
*Confira essa página com f12(inspecionar) na aba console do DevTools para ver como ficou.
Clique aqui para ver a resolução e explicação do Exercício: Criando Arrays

Código do Script

// a- Nome de três frutas
  const frutas = ["Maçã", "Banana", "Morango"];
  
  // b- 5 números
  const numeros = [10, 25, 42, 7, 99];
  
  // c- Cores favoritas (4 cores)
  const coresFavoritas = ["Azul", "Preto", "Verde", "Roxo"];
  
  // Exibindo os arrays no console
  console.log("Frutas:", frutas);
  console.log("Números:", numeros);
  console.log("Cores Favoritas:", coresFavoritas);

Dissecando o Script: Estrutura dos Arrays

Neste exercício, aplicamos a sintaxe básica dos Arrays para armazenar diferentes coleções de dados utilizando colchetes ([ ]) e separando os valores por vírgula.

1. Tipos de Dados nos Arrays

  • Array de Frutas (frutas): Guarda 3 textos (strings) intercalados entre aspas ("Maçã", "Banana", "Morango").
  • Array de Números (numeros): Guarda 5 valores numéricos diretamente, sem o uso de aspas.
  • Array de Cores (coresFavoritas): Outra coleção de textos, contendo exatamente 4 elementos.

2. Regras Fundamentais ao Criar Arrays

  • Uso de Colchetes ([ ]): Delimitam o início e o fim da lista.
  • Separação por Vírgula: Cada item dentro do array precisa ser separado por uma vírgula.
  • Uso de const: É a boa prática recomendada para declarar arrays em JavaScript.
