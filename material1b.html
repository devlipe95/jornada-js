Crie uma pagina com:

  • A - Crie uma div com id="caixa" escrito "Minha Caixa"
  • B - Aplique CSS: fundo cinza, padding 20px, texto centralizado
  • C - Crie 3 botões: "Vermelho", "Verde" e "Azul"
  • D - Ao clicar nos botões, altere a cor de fundo da caixa para a cor correspondente
Minha Caixa

Explicação do JS

Código utilizado:

const caixa = document.getElementById('caixa');
            const btnVermelho = document.getElementById('btnVermelho');
            const btnVerde = document.getElementById('btnVerde');
            const btnAzul = document.getElementById('btnAzul');
            
            btnVermelho.addEventListener('click', function() {
                caixa.style.backgroundColor = 'red';
            });
            
            btnVerde.addEventListener('click', function() {
                caixa.style.backgroundColor = 'green';
            });
            
            btnAzul.addEventListener('click', function() {
                caixa.style.backgroundColor = 'blue';
            });

Traduzindo o script para português:

Nas quatro primeiras linhas temos const caixa = document.getElementById('caixa'); até os botões. Sabendo que const cria um slot com valor imutável e document.getElementById busca um elemento na página pela sua id, temos quatro slots imutáveis guardando a caixa e cada um dos três botões.
Traduzindo esse bloco inicial: "No HTML, procure pelos elementos com id 'caixa', 'btnVermelho', 'btnVerde' e 'btnAzul', e guarde cada um dentro do seu respectivo slot."

Na linha seguinte temos btnVermelho.addEventListener('click', function() {. O termo btnVermelho chama o slot do primeiro botão, addEventListener('click', ...) escuta quando o usuário clica nele, e function() { abre o bloco de código que vai rodar.
Traduzindo essa instrução: "Avisamos ao 'btnVermelho' para ficar ouvindo a tela e, no exato momento em que receber um clique, executar a função contida nele."

Dentro da função temos caixa.style.backgroundColor = 'red';. Aqui, caixa chama o nosso slot da div, style acessa as propriedades visuais (CSS) desse elemento, backgroundColor especifica a cor de fundo, e o sinal de = atribui a cor 'red' (vermelho).
Traduzindo a linha interna: "Acesse o estilo visual do elemento 'caixa' e mude a sua cor de fundo para vermelho."

Repetimos a mesma estrutura com btnVerde e btnAzul mudando a propriedade style.backgroundColor para 'green' e 'blue'.

Resumo final:

Juntando todas essas traduções, o código está dizendo: "Mapeie a caixa e os três botões. Fique escutando o clique em qualquer um dos botões. Quando um botão for clicado, altere a propriedade de estilo do fundo da caixa para a cor correspondente." É por isso que, ao clicar em "Vermelho", "Verde" ou "Azul", a cor do elemento muda na hora.
