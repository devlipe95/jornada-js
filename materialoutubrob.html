O que é o Bootstrap?

O Bootstrap é uma biblioteca pronta com centenas de visuais e componentes pré-configurados (como botões, caixas de alerta e menus). Ele permite criar sites modernos, bonitos e que se adaptam a celulares e computadores sem precisar escrever todo o estilo do zero.

Como funcionam as classes btn btn-primary, btn-success, etc.?

A classe base btn avisa ao Bootstrap que aquele elemento é um botão (dando o formato arredondado, margens internas e cursor de clique). As classes complementares (como btn-primary para azul ou btn-success para verde) definem a cor de fundo e do texto de acordo com a paleta de cores do Bootstrap.

Como foram criados os 4 alertas?

Utilizamos as classes de alerta do Bootstrap (alert alert-success, alert-danger, alert-warning e alert-info). Elas criam automaticamente caixas coloridas com bordas e fundos suaves para sinalizar diferentes tipos de mensagens ao usuário.

Como funciona a animação do botão principal?

Criamos um efeito de "pulso" usando @keyframes chamado pulsoAtencao. A cada ciclo, o botão aumenta ligeiramente de tamanho (de 100% para 108%) e solta uma "onda" de luz azul ao redor dele, chamando a atenção do visitante. A regra infinite faz com que esse efeito continue repetindo.

Como funciona o efeito hover em todos os botões?

Usamos a classe personalizada btn-custom-hover. Quando o mouse passa por cima de qualquer botão (:hover), o CSS aplica um deslocamento suave para cima (translateY(-4px)) e projeta uma leve sombra, dando a impressão tátil de que o botão está "flutuando" para ser clicado.
