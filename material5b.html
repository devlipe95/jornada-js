Registros de um Dev Aprendiz

Opa, tudo certo? Não precisa prestar atenção em mim, sou só o placeholder da casa. O desafio em JS começa no bloco a seguir!

Usando a função, faça uma conta de soma, subtração e multiplicação:

  • A) 55
  • B) 30
*Confira essa página com f12(inspecionar) na aba console do DevTools para ver as respostas!
Clique aqui para ver o código e a explicação detalhada

Código do Script


              function calcularOperacoes(num1, num2) {
                const soma = num1 + num2;
                const subtracao = num1 - num2;
                const multiplicacao = num1 * num2;
              
                console.log(`Soma: ${num1} + ${num2} = ${soma}`);
                console.log(`Subtração: ${num1} - ${num2} = ${subtracao}`);
                console.log(`Multiplicação: ${num1} * ${num2} = ${multiplicacao}`);
              }
              
              
              calcularOperacoes(55, 30);

Dissecando o Script: Entendendo o Código Passo a Passo

Vamos analisar como a função calcularOperacoes funciona, detalhando o significado de cada comando e identificador utilizado.

1. Declaração da Função e Parâmetros

  • function: Palavra-chave do JavaScript usada para declarar (criar) uma função, que é um bloco de código reutilizável.
  • calcularOperacoes: Nome dado à função para identificá-la e chamá-la posteriormente.
  • (num1, num2): Parâmetros (variáveis de entrada). Eles funcionam como "espaços reservados" que receberão os números que você passar para a função.
  • { ... }: As chaves delimitam o corpo da função. Todo o código contido dentro delas só é executado quando a função é chamada.

2. Criação de Variáveis e Operações Matemáticas

  • const: Declara uma variável cujo valor é fixo e não mudará depois de calculado.
  • soma, subtracao, multiplicacao: Nomes das variáveis criadas para armazenar os resultados de cada conta.
  • =: Operador de atribuição. Ele pega o resultado da conta do lado direito e o guarda na variável do lado esquerdo.
  • +, -, *: Operadores aritméticos que realizam, respectivamente, soma, subtração e multiplicação.

3. Exibição de Resultados com Template Literals

  • console.log(...): Função nativa do JavaScript usada para exibir dados no console do navegador ou no terminal.
  • ` ... ` (Crases): Recurso chamado Template Literals (ou Template Strings). Permite intercalar texto fixo com variáveis de forma simples.
  • ${ ... }: Sintaxe de interpolação. Tudo o que fica entre as chaves do cifrão é avaliado como código JavaScript e substituído pelo seu valor real na mensagem.

4. Chamada da Função

  • calcularOperacoes(55, 30);: Instrução que executa a função. Os valores 55 e 30 são repassados aos parâmetros num1 e num2, disparando toda a sequência de cálculos e mensagens.
