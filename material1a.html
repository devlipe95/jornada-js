Bem-vindo

Explicação do JS

Código utilizado:

const titulo = document.getElementById('titulo');
            const botao = document.getElementById('botao');
            
            botao.addEventListener('click', function() {
                titulo.textContent = 'Bem-vindo ao Meu Site! 🚀';
            });

Traduzindo o script para português:

O código começa escrito const titulo. Sabendo que const cria um slot com valor imutável e titulo é o apelido desse slot, temos um slot imutável chamado "titulo".
Depois temos o sinal de =. Fique atento a este detalhe: em programação, tudo à esquerda do sinal de igual guarda o resultado de tudo o que é processado à direita.
Em seguida, temos document. (que significa acessar o arquivo HTML) juntamente com getElementById('titulo') (que significa "procure um elemento que tenha a id 'titulo'").
Traduzindo toda essa primeira linha, const titulo = document.getElementById('titulo'); se transforma em: "No HTML, procure pelo elemento que tem a id 'titulo' e guarde ele dentro do slot chamado titulo."

Na segunda linha temos const botao = document.getElementById('botao');. Traduzindo essa parte: "No HTML, procure pelo elemento que tem a id 'botao' e guarde ele dentro do slot chamado botao."

Na linha seguinte temos botao.addEventListener('click', function() {. Aqui, botao é o elemento que guardamos antes, addEventListener('click', ...) significa "fique ouvindo e esperando por um clique do usuário", e function() { é o bloco de instruções que vai rodar assim que esse clique acontecer.
Traduzindo isso: "Avisamos ao elemento 'botao' para ficar ouvindo a tela e, no exato momento em que ele receber um clique, executar a função que está contida nele."

Dentro da função temos a instrução titulo.textContent = 'Bem-vindo ao Meu Site! 🚀';. O termo titulo chama o elemento que guardamos na primeira linha, textContent significa "o texto contido dentro da tag", e o sinal de = atribui um novo valor para esse texto.
Traduzindo a linha interna: "Mude o texto interno do nosso elemento 'titulo' para a frase 'Bem-vindo ao Meu Site! 🚀'."

Por fim, o símbolo }); serve para fechar o bloco da função e encerrar o escutador de eventos do botão.

Resumo final:

Juntando todas essas traduções, o código completo está dizendo: "Pegue o título e o botão da página. Fique esperando o botão ser clicado. Quando o clique acontecer, troque o texto do título por 'Bem-vindo ao Meu Site! 🚀'." E é exatamente por isso que, quando você clica no botão do exercício prático, o texto da tela muda na hora.
