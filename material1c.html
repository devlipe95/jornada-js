Crie uma pagina com:

  • A - Um contador na tela, com botões de adicionar (+5) e subtrair (-5)
  • B - Ao chegar no valor 10 (ou maior), mude a cor de fundo da página (body)
  • C - Ao chegar no valor 10 (ou maior), exiba uma mensagem de alerta/aviso

Contador: 0

Explicação do JS

Código utilizado:

let numero = 0;
            
            const contadorSpan = document.getElementById('contador');
            const btnMais = document.getElementById('btnMais');
            const btnMenos = document.getElementById('btnMenos');
            const mensagemP = document.getElementById('mensagem');
            
            function verificarValor() {
                if (numero >= 10) {
                    document.body.style.backgroundColor = 'lightgreen';
                    mensagemP.textContent = 'Parabéns! Você atingiu 10 ou mais! 🎉';
                } else {
                    document.body.style.backgroundColor = 'white';
                    mensagemP.textContent = '';
                }
            }
            
            btnMais.addEventListener('click', function() {
                numero = numero + 5;
                contadorSpan.textContent = numero;
                verificarValor();
            });
            
            btnMenos.addEventListener('click', function() {
                numero = numero - 5;
                contadorSpan.textContent = numero;
                verificarValor();
            });

Traduzindo o script para português:

O código começa com let numero = 0;. Sabendo que let cria um slot de memória onde o valor pode ser alterado depois e numero é o nome desse slot, criamos uma caixa mutável que começa guardando o número 0.
Em seguida, temos os comandos const com document.getElementById(...). Traduzindo essa parte: "No HTML, procure e capture o texto do contador, os dois botões e o parágrafo da mensagem, guardando cada um em seu slot imutável."

Depois definimos a função function verificarValor() {. O termo function guarda um conjunto de regras que podemos rodar quando quisermos, e verificarValor é o nome dado a esse bloco.
Dentro dessa função temos a dica do exercício: if (numero >= 10) {. A palavra if significa "se" e a expressão numero >= 10 testa se o valor dentro da nossa variável é maior ou igual a 10.
Traduzindo o bloco do if: "SE o número guardado for maior ou igual a 10, mude o fundo da página (document.body.style.backgroundColor) para verde claro e escreva a frase de parabéns na mensagem (mensagemP.textContent)."
Logo abaixo temos else {. A palavra else significa "senão" (o que fazer se a condição do if for falsa).
Traduzindo o bloco do else: "SENÃO (caso o número seja menor que 10), mantenha o fundo do body branco e limpe o texto da mensagem para ela sumir."

Nas linhas seguintes temos os escutadores de evento btnMais.addEventListener('click', function() { ... }) e btnMenos.addEventListener('click', function() { ... }).
Na instrução numero = numero + 5;, pegamos o valor atual da variável e somamos 5 a ele.
Na instrução contadorSpan.textContent = numero;, atualizamos o texto da tela para mostrar o novo valor somado.
E na linha verificarValor();, chamamos a função que criamos para checar se o número bateu a meta de 10.
Traduzindo o clique dos botões: "Quando clicar no botão +5 (ou -5), altere o valor do número, atualize o texto na tela e rode a verificação do 'if' para saber se o fundo deve mudar de cor e se a mensagem deve aparecer."

Resumo final:

Juntando todas essas traduções, o código está dizendo: "Guarde um número começando em 0. Sempre que os botões de +5 ou -5 forem clicados, atualize esse número e a tela. Em seguida, teste com a regra do 'if': se o número for 10 ou mais, pinte o fundo da tela de verde e exiba o aviso; se for menor, mantenha o fundo normal." E é por isso que a cor e a mensagem reagem automaticamente quando o contador atinge 10.
