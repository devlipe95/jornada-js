Crie uma pagina com:

  • A - Campo de Nome (mínimo 3 letras)
  • B - Campo de Email (precisa ter @)
  • C - CSS: classes ".erro" e ".ok"
  • D - JS: validar ao clicar em "Enviar" (usando preventDefault)
  • E - Mostrar mensagem de sucesso




Explicação do JS

Código utilizado:

const meuFormulario = document.getElementById('meuFormulario');
            const campoNome = document.getElementById('nome');
            const campoEmail = document.getElementById('email');
            const mensagemStatus = document.getElementById('mensagemStatus');
            
            meuFormulario.addEventListener('submit', function(event) {
                event.preventDefault();
            
                const nome = campoNome.value.trim();
                const email = campoEmail.value.trim();
            
                if (nome.length < 3) {
                    mensagemStatus.textContent = 'Erro: O nome deve ter pelo menos 3 letras!';
                    mensagemStatus.className = 'erro';
                } else if (!email.includes('@')) {
                    mensagemStatus.textContent = 'Erro: Digite um e-mail válido com @!';
                    mensagemStatus.className = 'erro';
                } else {
                    mensagemStatus.textContent = 'Formulário enviado com sucesso! 🚀';
                    mensagemStatus.className = 'ok';
                }
            });

Traduzindo o script para português:

Nas quatro primeiras linhas temos const meuFormulario = document.getElementById('meuFormulario'); e os demais elementos. Sabendo que const cria um slot com valor imutável e document.getElementById busca um elemento da página pela id.
Traduzindo o bloco inicial: "No HTML, procure pelo formulário, pelo campo de nome, pelo campo de e-mail e pelo parágrafo de status, e guarde cada um dentro do seu slot imutável."

Na linha seguinte temos meuFormulario.addEventListener('submit', function(event) {. O termo meuFormulario chama o slot do formulário, addEventListener('submit', ...) escuta a tentativa de envio do formulário, e event representa o evento que acabou de acontecer.
Traduzindo a escuta do formulário: "Avisamos ao formulário para ficar atento ao momento de envio (submit) e disparar a função."

A primeira linha dentro da função é event.preventDefault();. O método preventDefault() impede o comportamento padrão do navegador, que seria recarregar a página imediatamente ao enviar o formulário.
Traduzindo a instrução: "Cancele o recarregamento automático da página para que possamos validar os dados primeiro usando o JavaScript."

Nas duas linhas seguintes temos const nome = campoNome.value.trim(); e const email = campoEmail.value.trim();. A propriedade value pega o texto digitado pelo usuário e trim() remove espaços vazios desnecessários do início e do fim.
Traduzindo o resgate dos dados: "Extraia o texto limpo digitado dentro do campo de nome e do campo de e-mail e guarde em novos slots temporários."

Em seguida temos a condição do nome: if (nome.length < 3) {. A propriedade length conta a quantidade de caracteres e o sinal de < verifica se é menor que 3.
Traduzindo o primeiro teste: "SE o tamanho do nome for menor que 3 letras, escreva a mensagem de erro no texto e aplique a classe CSS 'erro'."

Na linha do else if (!email.includes('@')) { temos um segundo teste caso a primeira validação tenha passado. O método includes('@') checa se existe a letra '@' no e-mail, e a exclamação ! inverte o resultado (significando 'NÃO contém').
Traduzindo o segundo teste: "SENÃO, SE o e-mail NÃO contiver o símbolo '@', escreva a mensagem de erro no texto e aplique a classe CSS 'erro'."

Por fim temos o bloco do else {, que roda se todas as validações anteriores passarem sem erros.
Traduzindo o bloco de sucesso: "SENÃO (se o nome tiver 3 ou mais letras E o e-mail tiver '@'), exiba a mensagem de sucesso e aplique a classe CSS 'ok'."

Resumo final:

Juntando todas essas traduções, o código está dizendo: "Mapeie os campos do formulário. Quando o usuário tentar enviar, bloqueie a atualização da tela com o preventDefault(). Em seguida, teste: se o nome for menor que 3 letras ou o e-mail não tiver '@', mostre um aviso vermelho usando a classe 'erro'; caso contrário, exiba a mensagem de confirmação verde usando a classe 'ok'."
