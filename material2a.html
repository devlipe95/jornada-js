ATIVIDADE 1 — Responda:

  • a- O que é um formulário?
  • b- Qual a função do HTML em um formulário?
  • c- Qual a função do CSS em um formulário?
  • d- Qual a função do JS em um formulário?

a) O que é um formulário?

Um formulário web é uma seção de uma página HTML projetada para coletar informações enviadas pelo usuário (como nome, e-mail, senha ou mensagens) e transmiti-las para um servidor ou processá-las localmente.

b) Qual a função do HTML em um formulário?

O HTML define a estrutura e o conteúdo do formulário. Ele cria os elementos interativos (como caixas de texto <input>, botões <button>, caixas de seleção <select> e rótulos <label>) e organiza a hierarquia dos campos para os navegadores e leitores de tela.

c) Qual a função do CSS em um formulário?

O CSS é responsável pela apresentação e estilo visual. Ele define layout, espaçamentos, cores, fontes, alinhamentos e estados visuais (como alterar a cor da borda quando um campo está em foco ou destacar campos inválidos), tornando o formulário legível, atraente e acessível.

d) Qual a função do JS em um formulário?

O JavaScript gerencia o comportamento e a interatividade. Ele é usado para validar os dados em tempo real antes do envio (por exemplo, checar se um e-mail é válido), manipular o envio sem recarregar a página (via requisições assíncronas/AJAX) e criar dinâmicas avançadas (como exibir campos condicionais ou máscaras de formatação de CPF/telefone).
